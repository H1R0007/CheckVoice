# ЧекВойс

Голосовой учёт покупок для платформы Салют (Сбер).
Диктуйте товары и цены — приложение записывает, категоризирует и считает.

---

## Возможности

### Голосовой ввод
- «Молоко 89 рублей» — добавить товар
- «Молоко 89 рублей 50 копеек» — с копейками
- «Добавь хлеб 45» — с командой
- После добавления ассистент продолжает слушать — диктуйте подряд

### Управление чеком
- «Удали молоко» / «Удали первый пункт»
- «Измени цену молока на 95»
- «Отмени последнее» — отменить только что добавленный товар
- «Очисти чек» — удалить все позиции
- «Сохрани чек» — сохранить в историю

### Информация
- «Сколько итого?» — услышать сумму
- «Перечисли чек» — услышать все товары

### Навигация
- «Покажи историю» / «Покажи статистику» / «Покажи настройки»
- «Открой последний чек»
- «Редактируй последний чек»
- «Удали последний чек»

### Аналитика
- «Сколько потрачено на мясо?» — расходы по категории
- Статистика за неделю, месяц или всё время
- 19 категорий, 900+ ключевых слов для автоматической категоризации

### Данные
- Экспорт в CSV (Excel / Google Sheets)
- Экспорт в JSON (полный бэкап)
- Импорт из JSON с объединением или заменой данных
- Персональное обучение категорий — приложение запоминает исправления

### Интерфейс
- Три темы: Светлая, Изумруд, Полночь
- Свайп влево для удаления товара
- Редактирование цены касанием

## Установка

### Требования
- Node.js 18+
- Аккаунт на SmartApp Studio: https://developers.sber.ru/studio/

### Шаги

**1. Клонирование**

git clone https://github.com/H1R0007/CheckVoice.git
cd CheckVoice
npm install

**2. SmartApp Code (сценарий)**

Откройте SmartApp Studio
Создайте проект Code for SmartApp
Загрузите содержимое папок src/sc/ и src/js/
Соберите проект, скопируйте Webhook URL
**3. Canvas App**

Создайте проект CanvasApp в SmartApp Studio
Привяжите Webhook из шага 2
Скопируйте токен: Профиль → Настройки → Эмулятор
**4. Конфигурация**

cp .env.sample .env

Заполните .env:

REACT_APP_TOKEN="ваш_токен"
REACT_APP_SMARTAPP="название_вашего_CanvasApp"

**5. Запуск**

npm start

**Продакшн-сборка**

npm run build
